# Baljinder Singh — Portfolio

A responsive React + Vite portfolio with a warm editorial visual direction, lime accents, soft purple details, motion-based reveals, and lightweight CSS 3D effects.

## Run locally

1. Install **Node.js LTS**.
2. Extract this folder and open it in VS Code.
3. Open the VS Code terminal in this folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL Vite prints (usually `http://localhost:5173`).

To create a production build:

```bash
npm run build
npm run preview
```

## Personalise before publishing

Open `src/main.jsx` and update:

- The college name if you want its official full name displayed.
- The project descriptions, tags, demos and repository links as your work is ready to publish.
- The email address (`hello@baljindersingh.dev`) with your real contact email.
- The GitHub and LinkedIn URLs in the footer with your profiles.
- The "Based in Punjab" line if you want a different location or prefer to remove it.

The project cards currently describe NEXUS, CampusMind AI and NEXORA STUDIO as concepts / selected explorations. Keep or edit them to match what you are comfortable publicly claiming.

## Stack

- React 18
